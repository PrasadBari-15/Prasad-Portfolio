# Prasad Bari — Portfolio

A responsive personal portfolio built with React, Vite, CSS, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Build for deployment

```bash
npm run build
```

Vite generates the production website in `dist/`.

## Personal photo

Add your profile photo to `public/profile-photo.jpg`. The page has a fallback monogram if the photo is not present.

## Deploy

Import this repository into Vercel. Framework preset: Vite, build command: `npm run build`, output directory: `dist`.
